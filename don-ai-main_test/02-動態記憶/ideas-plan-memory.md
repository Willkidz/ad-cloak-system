# 想法與規劃

本文件記錄用戶的想法、計畫和未來方向。AI 在開始新任務前應參考此文件，了解用戶的整體思路，避免與既定方向衝突。

> **使用方式**：新想法按日期倒序記錄（最新的在最前面），每條記錄包含想法描述、背景原因、可能的行動方案、優先度和狀態。

---

## 記錄模板

<example type="idea-record-template">

```markdown
### YYYY-MM-DD — 主題

**想法**：一句話描述
**背景**：為什麼有這個想法
**可能的行動**：下一步可以做什麼
**優先度**：P0（緊急）/ P1（重要）/ P2（一般）/ P3（低優先）
**狀態**：構想中 / 評估中 / 已決定 / 已執行 / 已放棄
```

</example>

---

## 優先度定義

| 優先度 | 定義 | 說明 |
| :--- | :--- | :--- |
| P0 | 緊急 | 影響營收或系統穩定性，需立即處理 |
| P1 | 重要 | 對業務有顯著影響，應在近期排入計畫 |
| P2 | 一般 | 有價值但不急迫，可在空檔時處理 |
| P3 | 低優先 | 長期構想或探索性想法，有空再看 |
