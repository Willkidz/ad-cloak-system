> **TL;DR**: 本報告分析了 Meta 廣告受眾策略的核心轉向：從「人工標籤定向」全面進入「演算法自動化定向」。報告指出，傳統的興趣與行為標籤權重正在下降，而 **Advantage+ 購物活動 (ASC)** 與 **Advantage+ 受眾** 已成為主流。針對博弈類廣告，報告強調了 **自定義受眾 (Custom Audiences)** 與 **類似受眾 (Lookalike Audiences)** 的持續價值，並提出透過「素材內容」引導演算法尋找高價值玩家的具體路徑。

# Meta 廣告受眾策略分析：從精準定向到演算法自動化

## 1. 受眾策略的典範轉移

在 2026 年，Meta 的受眾定向邏輯已發生根本性變化。

<rule id="audience-shift-rule">
- **過去**：依賴人工設定精細的興趣標籤（如：對「德州撲克」感興趣）。
- **現在**：演算法透過分析廣告素材吸引的用戶行為，自動擴展受眾。**受眾設定越寬鬆，演算法的優化空間越大**。
</rule>

---

## 2. 核心受眾工具與應用

<example id="audience-tools">
| 工具名稱 | 核心邏輯 | 博弈專案應用建議 |
| :--- | :--- | :--- |
| **Advantage+ 受眾** | 演算法全自動尋找受眾，僅需設定地區與年齡下限。 | 適用於大預算、廣撒網階段，讓演算法自行學習。 |
| **自定義受眾 (CA)** | 基於自有數據（如：網站訪客、LINE 好友名單）。 | 用於「再行銷」，針對已互動用戶進行精準轉化。 |
| **類似受眾 (LAL)** | 尋找與現有高價值玩家特徵相似的新用戶。 | 核心增長引擎，建議使用「高額儲值玩家」作為種子名單。 |
| **興趣定向** | 傳統標籤定向。 | 僅用於新帳號冷啟動階段，提供演算法初始方向。 |
</example>

---

## 3. 針對博弈類廣告的受眾路徑

<step id="audience-pathway">
1.  **冷啟動階段**：使用寬泛的興趣標籤（如：遊戲、體育、投資）結合「素材即定向」策略，讓演算法收集初始數據。
2.  **數據累積階段**：建立「網站點擊」與「表單提交」的自定義受眾。
3.  **規模化階段**：利用 1%-3% 的類似受眾 (LAL) 進行擴張，並同步開啟 Advantage+ 受眾以獲取演算法紅利。
4.  **精準收割階段**：針對 CA 受眾進行排除或特定優惠推送，提升 LTV (生命週期價值)。
</step>

---

## 4. 結論：受眾與素材的協同效應

<boundaries id="audience-conclusion">
受眾策略不再是孤立的設定，而是與素材深度綁定的過程。**好的受眾策略是「給演算法足夠的自由度，同時用精準的素材作為過濾器」**。對於「博富」專案，應減少對複雜興趣組合的依賴，轉而強化種子名單的品質與素材的受眾篩選能力。
</boundaries>
