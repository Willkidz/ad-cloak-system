Config API 結構分析：

1. MASTER_PIXEL_MAP: 硬編碼在 Build Config 裡，key 是 tag (cs/js/ls/ms/cb/jb/lb/mb/cx/jx/lx/mx/n18/n14/n22)
2. LINE_MAP: 從 DataTable (lineResp) 讀取，key 是 tag
3. AD_MAP: 從 DataTable (adResp) 讀取，key 是 ad_code，值是 { pixels: [{pixel, token}] }

AS01=JS01=CS01=MS01=LS01 的邏輯：
- AS 是爆分的 ad_code 前綴
- JS/CS/MS/LS 是不同 tag（不同 LINE OA）
