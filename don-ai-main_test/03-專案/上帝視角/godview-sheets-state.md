> **TL;DR**: 當前「廣告成效儀表板」Google Sheet 的佈局：Row 2 為控制面板（日期、範圍、最後更新 `F2`、同步 ID `H2:36`）；Row 3-7 為偵測率區塊，按 code 組（AS/AX/AB/合計）分組，4 欄（A:D）；Row 10 為廣告成效標題列（A-N 共 14 欄：code、廣告帳戶ID、素材說明、狀態、累計消耗/添加/CPA、區間消耗/成果/添加、流失、添加占比、單次添加/成果）。與 n8n 預期格式存在**四項關鍵差異**：(1) 偵測率應按人員 C/J/L/M 分組而非 code 組；(2) 偵測率應為 5 欄（A:E）而非 4 欄；(3) 標題列應在 Row 11 而非 Row 10（n8n 寫入 `A12:N` 會錯位）；(4) 缺少人員維度偵測率。

# 成效分頁目前狀態

本文記錄了「廣告成效儀表板」Google Sheet 的當前欄位結構與內容佈局，並點出其與 n8n 自動化流程預期格式之間的主要差異。

## 與 n8n 預期格式的關鍵差異

<rule id="format-discrepancy">
以下幾點是目前工作表格式與 n8n 預期格式不符的地方，可能導致自動化流程寫入資料時發生錯位或失敗。

1.  **偵測率分組方式不同**：目前是按「code組」(AS/AX/AB) 區分，而 n8n 預期的是按「人員」(C/J/L/M) 區分，公式為 `=IF(C4="","",D4/C4)`。
2.  **偵測率區塊欄位數不同**：目前只有 4 欄 (A:D)，n8n 預期為 5 欄 (A:E)。
3.  **廣告數據起始列不同**：標題列在 Row 10，而 n8n 預期在 Row 11，這會導致 `n8n 寫入 A12:N` 的操作發生錯位（n8n 預期 Row 12 為數據起始列，但目前 Row 11 才是）。
4.  **缺少人員維度的偵測率**：目前的工作表中沒有按人員分的偵測率數據。
</rule>

---

## 結論

當前的工作表結構與 n8n 自動化流程的預期存在明顯不匹配，特別是起始寫入位置和欄位結構的差異。在執行 n8n 工作流之前，必須先解決這些格式不一致的問題，以確保數據能被正確寫入。
