# 社群行銷王 價格與服務分析報告

本報告基於 社群行銷王 API 提供的服務清單進行分類與價格分析。社群行銷王是台灣本地的社群行銷平台，提供在地化的真人按讚、留言與直播人數等服務，計價幣別為新台幣 (TWD)。

## 1. 服務總覽

- **總服務數量**：105 個
- **涵蓋平台數**：6 個
- **價格範圍 (USD)**：$0.7812 - $1406.2500 / 千次
