# kravdo.lol 介面設計優化建議書

> **文件摘要**：本建議書基於對 kravdo.lol 現有介面的深度分析、四個主要 SMM Panel 競品的研究，以及電商平台處理大量 SKU 的設計模式研究，針對「722 個服務卡片網格導致購買體驗困難」的核心問題，提出一套具體可執行的介面重構方案。

---

## 第一章：問題診斷——為何卡片網格讓用戶「買東西很吃力」

### 1.1 認知負荷超標：722 個選項的視覺暴力

心理學研究中著名的「選擇悖論（Paradox of Choice）」指出，選項過多反而會降低用戶的決策意願與滿意度。kravdo.lol 目前的設計，在用戶進入頁面的第一秒，就將 722 個服務的資訊全部拋向用戶，這直接觸發了認知超載（Cognitive Overload）。

每張卡片包含以下 6 至 7 個資訊點：平台圖標、品質等級標籤、服務名稱、每千單位價格、數量範圍、交付時間，以及一段描述文字。在 4 列的網格佈局下，用戶的眼睛必須以 Z 字型或 F 字型掃描路徑逐一閱讀，極易在第 5 至 10 張卡片後就放棄瀏覽。

### 1.2 篩選系統的設計陷阱

當前的篩選系統將三個維度的篩選器同時攤開：20+ 個平台標籤、15+ 個服務類型標籤，以及 5 個品質等級標籤。這個設計的問題在於，它要求用戶在購買之前，就必須理解並掌握這三個維度的含義，才能有效使用篩選器。對於不懂 SMM 術語的小白用戶而言，「超值版」、「精選真人」等詞彙本身就是障礙，更遑論要在三個維度之間做出正確的組合選擇。

### 1.3 同質化服務的比較困境

以「Instagram 粉絲」為例，目前有經濟版（NT$15）、標準版（NT$35）、高品質（NT$65）、精選真人（NT$150）等多個版本，這些卡片在網格中分散排列。用戶若想比較這四個版本的差異，必須在頁面中反覆尋找並記憶各卡片的資訊，這種「記憶型比較」的認知成本極高。

### 1.4 下單表單的空間困境

點擊「立即訂購」後，下單表單直接在卡片上展開。這個設計在密集的網格環境中，會讓用戶感到空間擁擠，且表單展開後視覺焦點仍然分散在周圍的其他卡片上，無法提供專注的結帳體驗。

## 第二章：競品研究——業界最佳實踐

### 2.1 傳統 SMM Panel：分組資料表模式

以 **smmpanel.com** 與 **smmstone.com** 為代表的傳統 SMM Panel，採用分組資料表（Grouped Data Table）的展示方式。

| 設計元素 | 具體做法 |
|---|---|
| 一級導航 | 平台圖標橫向滾動列（Facebook, Instagram, YouTube...） |
| 服務展示 | 表格形式，每行一個服務，欄位包含 ID、名稱、Rate/1000、Min、Max、平均時間 |
| 分組標題 | 用醒目的彩色標題行（如黃色或紫色）分隔不同服務類別 |
| 操作按鈕 | 每行末尾有「View」和「Buy Now」兩個按鈕 |

**優點**：資訊密度高，同類服務上下排列，比較效率極高，適合代理商和老客戶。

**缺點**：介面風格接近後台管理系統，對小白用戶不友善；手機端需要橫向滑動，體驗差。

### 2.2 創新 SMM Panel：專屬落地頁模式（最佳參考）

**naizop.com** 代表了目前業界最先進的小白友善設計模式，其核心邏輯是「讓用戶選擇，而不是讓用戶搜尋」。

| 設計層次 | 具體做法 |
|---|---|
| 首頁 | 平台圖標網格（Instagram, TikTok, YouTube...），點擊直接進入專屬頁面 |
| 品質切換 | 頁面頂部三個 Tab（Real / High Quality / Premium），附「有什麼不同？」說明連結 |
| 套餐選擇 | 預設套餐卡片（100粉 / 500粉 / 1000粉...），顯示原價、折扣價、折扣百分比 |
| 促銷標籤 | 「BEST SELLER」、「BULK PRICE」標籤，製造錨定效應 |
| 下單按鈕 | 底部大型 Buy Now 按鈕，即時顯示選中套餐的總價 |
| 相關服務 | 頁面底部橫向滾動的相關服務推薦（Buy Likes, Comments, Views...） |

這個設計的關鍵洞察是：**不讓用戶自己輸入數量，而是提供預設的套餐**。這一個改動就消除了「我應該買多少」的決策困難。

### 2.3 電商平台的大量 SKU 設計原則

Amazon 與蝦皮（Shopee）在處理數百萬 SKU 時，遵循以下核心原則：

**漸進式揭露（Progressive Disclosure）**：從不將所有商品平鋪。用戶的路徑是「首頁大類 → 子分類 → 商品列表 → 商品詳情」，每一步都只展示當前決策所需的資訊量。

**引導式銷售（Guided Selling）**：對於複雜的商品選擇，提供「選購精靈（Product Finder）」，透過 2 至 4 個問題（我的需求是什麼？我的預算是多少？）幫助用戶縮小選擇範圍，最終推薦 3 至 5 個最適合的選項。

**搜尋優先（Search-First）**：搜尋框始終位於最顯眼的位置，支援模糊搜尋與自動補全，服務於有明確購買目標的用戶。

## 第三章：介面設計建議——具體佈局方案

### 3.1 整體架構轉型

建議將現有的「單頁平鋪所有服務」架構，改為「首頁分發 + 平台專屬頁面」的兩層架構。

```
現有架構：
首頁（含 722 個服務卡片）

建議架構：
首頁（平台入口 + 熱門推薦 + 搜尋）
    ├── /ig  Instagram 專屬頁面（107 個服務，分類展示）
    ├── /fb  Facebook 專屬頁面（64 個服務，分類展示）
    ├── /yt  YouTube 專屬頁面（62 個服務，分類展示）
    ├── /tt  TikTok 專屬頁面（60 個服務，分類展示）
    └── ...  其他平台頁面
```

### 3.2 首頁佈局設計

**區塊一：Hero 區（保留現有設計，強化搜尋）**

保留現有的品牌標語與統計數字，但將搜尋框升級為頁面最核心的互動元素。搜尋框應支援中文關鍵字，並在輸入時即時顯示下拉建議（例如輸入「IG」立即顯示「Instagram 粉絲」、「Instagram 按讚」、「Instagram 觀看」等選項）。

**區塊二：平台入口（核心改動）**

將現有的橫向滾動標籤列，改為大型圖文按鈕網格。

```
桌面端佈局（每行 6 個）：
┌──────────┬──────────┬──────────┬──────────┬──────────┬──────────┐
│    IG    │    FB    │    YT    │    TT    │    TG    │    X     │
│Instagram │Facebook  │YouTube   │TikTok    │Telegram  │Twitter/X │
│  107 項  │  64 項   │  62 項   │  60 項   │  43 項   │  42 項   │
└──────────┴──────────┴──────────┴──────────┴──────────┴──────────┘
                    [ 查看全部 32 個平台 ▼ ]

手機端佈局（每行 3 個）：
┌──────┬──────┬──────┐
│  IG  │  FB  │  YT  │
├──────┼──────┼──────┤
│  TT  │  TG  │  X   │
└──────┴──────┴──────┘
    [ 查看全部平台 ]
```

**區塊三：熱門推薦（快速轉化入口）**

僅展示全站最暢銷的 4 至 6 個套餐，以橫向卡片排列。每張卡片只顯示：服務名稱、最低起始價格、一個「立即購買」按鈕。這個區塊服務於「我不知道要買什麼，但我想快速購買」的用戶。

### 3.3 平台專屬頁面佈局設計

以 Instagram 專屬頁面（/ig）為例：

**頂部：麵包屑導航**

`首頁 > Instagram 服務`

**服務類型 Tab 列（二級導航）**

```
[ 粉絲/追蹤 ] [ 按讚/愛心 ] [ 觀看 ] [ 留言 ] [ 限時動態 ] [ 收藏 ] ...
```

預設選中「粉絲/追蹤」Tab。

**品質切換器（三級導航）**

```
品質方案：[ 經濟版 ] [ 標準版 ] [ 高品質 ] [ 精選真人 ]
                                              ℹ️ 各版本有什麼不同？
```

點擊「ℹ️」展開白話文說明：

| 版本 | 適合對象 | 特點 |
|---|---|---|
| 經濟版 | 想快速衝人數、預算有限 | 速度快、價格最低，可能有少量掉粉 |
| 標準版 | 一般用途、性價比最高 | 品質穩定，少量保固 |
| 高品質 | 重視帳號安全 | 真實帳號外觀，30 天保固 |
| 精選真人 | 品牌帳號、長期經營 | 台灣真實用戶，永久保固，最高安全 |

**套餐選擇器（核心展示區）**

```
桌面端（4 列網格）：
┌─────────────┬─────────────┬─────────────┬─────────────┐
│   100 粉絲  │   500 粉絲  │  1,000 粉絲 │  5,000 粉絲 │
│             │             │  ★ 最暢銷   │             │
│   NT$3.5    │   NT$17.5   │   NT$35     │   NT$175    │
│             │             │             │  省 10%     │
└─────────────┴─────────────┴─────────────┴─────────────┘
┌─────────────┬─────────────┬─────────────┬─────────────┐
│ 10,000 粉絲 │ 20,000 粉絲 │ 50,000 粉絲 │  自訂數量   │
│             │  省 15%     │  省 20%     │             │
│   NT$350    │   NT$595    │  NT$1,400   │  輸入數量 → │
└─────────────┴─────────────┴─────────────┴─────────────┘
```

### 3.4 下單流程設計（最短路徑）

採用**彈出視窗（Modal）或側邊抽屜（Drawer）**的形式，將下單流程從擁擠的卡片網格中獨立出來。

**步驟一：選擇套餐**（在套餐選擇器頁面完成）

用戶點擊心儀的套餐卡片，卡片出現選中狀態（藍色邊框 + 勾選圖標）。

**步驟二：填寫資料**（彈出視窗）

```
╔══════════════════════════════════════════╗
║  確認訂單                          [×]  ║
╠══════════════════════════════════════════╣
║  已選：Instagram 粉絲 1,000 個（標準版）║
║  總價：NT$35                            ║
╠══════════════════════════════════════════╣
║  請輸入您的 Instagram 帳號連結：        ║
║  ┌────────────────────────────────────┐ ║
║  │ https://www.instagram.com/您的帳號 │ ║
║  └────────────────────────────────────┘ ║
║  📌 範例：https://instagram.com/apple  ║
║  ⚠️ 請確認帳號為公開狀態              ║
╠══════════════════════════════════════════╣
║  [  取消  ]      [ 加入購物車 → ]      ║
╚══════════════════════════════════════════╝
```

**步驟三：結帳**（購物車頁面）

購物車頁面顯示所有已加入的服務，支援一次購買多個服務，然後統一結帳。

### 3.5 手機端（Mobile-First）關鍵設計點

**底部懸浮結帳列（Sticky Checkout Bar）**

當用戶在平台專屬頁面瀏覽時，螢幕底部始終懸浮顯示：

```
┌──────────────────────────────────────────┐
│ 已選：IG 粉絲 1,000 個  NT$35  [立即購買]│
└──────────────────────────────────────────┘
```

**觸控熱區優化**

所有可點擊元素（平台圖標、套餐卡片、按鈕）的最小尺寸應達到 44×44px，符合 Apple HIG 與 Google Material Design 的觸控標準。

**手機端平台導航**

在手機端，平台入口可採用蝦皮式的「左側大類 + 右側子類」雙聯設計，或者採用全螢幕的分類選擇頁面，避免在小螢幕上擠壓過多元素。

## 第四章：進階功能建議（可選實施）

### 4.1 「幫我選」精靈（Guided Selling Wizard）

針對完全不懂 SMM 的新用戶，在首頁增加一個「我不知道要買什麼，幫我選 →」的入口，引導用戶回答 3 個問題：

1. 您想推廣哪個平台？（Instagram / Facebook / YouTube...）
2. 您的主要目標是什麼？（增加粉絲 / 提升貼文曝光 / 獲得更多評論）
3. 您的預算大約是多少？（NT$100 以下 / NT$100-500 / NT$500 以上）

根據回答，系統推薦 3 個最適合的套餐，並說明推薦理由。

### 4.2 「進階列表模式」切換

為代理商和老客戶保留一個「切換至進階模式」的按鈕，進入類似 smmpanel.com 的分組資料表視圖，提供高密度的資訊比對功能。這樣可以同時服務小白用戶和進階用戶，而不必犧牲任何一方的體驗。

### 4.3 最近瀏覽與快速再購

在頁面頂部或用戶個人區塊，顯示「最近瀏覽」或「再次購買」的快捷入口，降低回購用戶的操作成本。

## 第五章：實施優先級建議

以下按照「對用戶體驗的提升幅度」與「開發成本」的比值，排列實施優先級：

| 優先級 | 改動項目 | 預期效果 | 開發成本 |
|---|---|---|---|
| P0（立即） | 首頁新增平台入口大圖標網格 | 大幅降低初始認知負荷 | 低 |
| P0（立即） | 新增品質版本白話文說明（ℹ️ 提示框） | 減少用戶疑惑與客服量 | 極低 |
| P1（優先） | 建立各平台的專屬服務頁面（從 IG 開始） | 提升轉化率，降低跳出率 | 中 |
| P1（優先） | 將下單表單改為彈出視窗 / 側邊抽屜 | 提升下單專注度 | 低 |
| P1（優先） | 手機端增加底部懸浮結帳列 | 顯著提升手機端轉化 | 低 |
| P2（次要） | 在套餐中新增預設數量套餐（不只是自訂） | 降低決策疲勞 | 中 |
| P3（長期） | 新增「幫我選」引導精靈 | 服務完全不懂 SMM 的新用戶 | 高 |
| P3（長期） | 新增進階列表模式切換 | 服務代理商用戶 | 中 |
