# 09-歸檔 — 說明

本資料夾存放已完成的專案、過期的資源、舊的日誌等不再活躍但需要保留的文件。

## 歸檔規則

1. **狀態驅動歸檔**：當專案完成或 SOP 廢棄時，將其 frontmatter 中的 `status` 改為 `archived`
2. **物理隔離**：所有 `status: archived` 的文件應移動到本目錄下相應的子目錄中
3. **搜索隔離**：AI 的默認搜索範圍應排除本目錄。只有當用戶明確要求「查找過去的歷史記錄」時，才應將搜索範圍擴大到本目錄
4. **動態記憶清理**：`02-動態記憶/` 中超過 30 天未修改的日誌文件，應進行「記憶整合」：提取有價值的長期知識存入 `04-資源與參考/`，然後將原日誌移至本目錄
5. **專案歸檔**：專案完成或暫停超過 3 個月後，整個資料夾移至本目錄
6. **保持原名**：歸檔文件保持原名，可選加 `{YYYYMM}-` 前綴標示歸檔時間

## 目錄結構

歸檔文件按來源資料夾分類存放：

```
09-歸檔/
├── 02-動態記憶/     # 過期的日誌和對話記錄
├── 03-專案/         # 已完成的專案
├── 04-資源與參考/   # 過時的技術資料
└── 06-SOP流程/      # 廢棄的操作流程
```
