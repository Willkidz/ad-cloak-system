# 「全行銷」公司企劃分析報告

> **文件版本**：v1.0 | **編製日期**：2026 年 3 月 28 日 | **機密等級**：內部使用

---

## 摘要

本報告針對擬成立之「全行銷」公司進行全面性的企劃分析。「全行銷」定位為新一代「全端智能流量與行銷自動化平台」，在台灣社群行銷產業高速成長的背景下，以既有的 Cloudflare 邊緣運算、廣告歸因系統（GodView）、流量過濾系統（Shadow Cloak）及 N8N 自動化工作流等核心技術為基礎，規劃涵蓋社群流量服務、智能斗篷、全鏈路歸因與競品情報四大服務模組。報告內容涵蓋市場定位與願景、服務項目規劃、技術架構建議、商業模式與定價策略、目標客群分析、競爭優勢分析、發展路線圖，以及風險評估與應對策略等八大面向，為公司創立提供完整的策略藍圖。

---

## 一、全行銷的定位與願景

### 1.1 市場背景

台灣數位行銷產業正處於高速成長期。根據 We Are Social 最新數據，台灣社群活躍使用者已達 **2,210 萬人**，佔總人口的 **95.3%** [1]。台灣網紅行銷市場規模已達 **2.39 億美元**，年成長率高達 **11.7%** [2]。全球網紅行銷市場預估至 2025 年將達 **325.5 億美元** [3]，而台灣社群商務市場預估年成長 **25.5%**，2025 年可達 **40.7 億美元** [4]。這些數據充分說明，社群行銷已從「選配」轉變為企業與個人品牌的「標配」。

然而，現有的社群流量服務平台（如 HDZ Bulk、iFans 等）大多停留在「賣讚、賣粉」的基礎層級，未能解決客戶在廣告歸因失準、帳號安全防護與數據驅動決策等方面的深層痛點。這正是「全行銷」切入市場的戰略機會。

### 1.2 品牌定位

**全行銷**定位為新一代「全端智能流量與行銷自動化平台」。不同於傳統 SMM Panel 僅提供單一的流量買賣服務，全行銷以「流量獲取 → 流量清洗 → 精準歸因 → 策略優化」四階段閉環為核心架構，為客戶提供一站式的黑科技行銷解決方案。品牌名稱中的「全」字，既代表「全平台覆蓋」，也象徵「全鏈路打通」的服務理念。

### 1.3 願景與使命

**願景**：成為亞洲領先的「真實影響力與自動化行銷引擎」，讓每一分行銷預算都能被精準追蹤、有效轉化。

**使命**：打破傳統流量買賣平台僅提供「虛榮指標」的侷限，透過技術創新賦能品牌、電商與自媒體實現可衡量的商業增長。

## 二、服務項目規劃

在 HDZ Bulk 現有 21 個平台、500+ 服務選項的基礎上，全行銷規劃 **四大核心服務模組** 與 **兩大增值服務**，形成完整的行銷生態閉環。

### 2.1 模組一：基礎社群流量矩陣

此模組對標 HDZ Bulk 與 iFans 的核心業務，但在平台覆蓋廣度與服務深度上進一步擴展。

| 平台類別 | 支援平台 | 服務項目 |
| :--- | :--- | :--- |
| 主流社群 | Facebook、Instagram、YouTube、TikTok、Threads、X (Twitter)、Twitch | 按讚、追蹤/粉絲、觀看、留言、分享、直播人數、Reels/Shorts 觀看 |
| 通訊與專業 | LINE（官方帳號好友數）、LinkedIn、Discord | 好友增長、連結互動、伺服器成員 |
| 論壇口碑 | PTT、Dcard、Mobile01 | 發文、推文/留言、議題操作、帳號租借 |
| 評價與在地 | Google Map、Google Play、App Store | 五星評價、下載量、應用評論 |
| 媒體曝光 | 經濟日報、LINE TODAY、Yahoo 新聞、Blogger | 新聞稿發布、口碑文章、部落格流量 |

相較於 HDZ Bulk，全行銷新增了 **Threads**（Meta 新興平台，台灣已有 665 萬用戶 [2]）、**小紅書**（跨境電商與美妝產業剛需）、**Lemon8**（年輕族群新寵）、**Mobile01**（3C 與汽車產業口碑重鎮）、**Podcast 平台** 與 **Telegram 頻道** 等服務，將支援平台數從 21 個擴展至 **28 個以上**。

### 2.2 模組二：智能斗篷與流量過濾（Shadow Cloak）

此為全行銷的獨家差異化服務，市場上幾乎無直接競品提供同類整合方案。

Shadow Cloak 系統透過 Cloudflare Workers 邊緣運算，在流量到達落地頁之前進行毫秒級的訪客身份判斷。系統根據 IP 地理位置、User-Agent 特徵、裝置指紋、瀏覽行為模式等多維度數據，將訪客分類為「真實用戶」或「審核員/機器人」。真實用戶被導向實際的行銷落地頁，而審核員與機器人則被無縫重定向至預先準備的安全頁面（白頁）。此服務對於投放高風險產業廣告（如保健品、金融產品、跨境電商）的客戶而言，是保護廣告帳號與確保業務連續性的關鍵工具。

服務內容包含：斗篷規則配置與管理後台、多域名輪替與自動切換、即時流量分析儀表板、自訂白頁模板庫，以及 API 串接支援。

### 2.3 模組三：全鏈路廣告歸因（GodView）

GodView 系統解決了 iOS 14.5 以來 ATT 隱私政策導致的廣告追蹤失準問題，這是所有 Facebook 廣告投放者的核心痛點。

系統提供「FB 廣告點擊 → 用戶加入 LINE 官方帳號 → 透過 Meta Conversions API (CAPI) 回傳轉換事件」的完整歸因鏈路。透過整合現有的 24 個 LINE OA 與 Facebook Business Manager（管理 10 個 ADS 像素），GodView 能精準追蹤每一個廣告觸發的 LINE 加好友行為，並將此轉換數據回傳至 Meta 廣告系統，幫助客戶的廣告演算法持續優化，有效降低獲客成本（CPA）。

服務內容包含：歸因像素部署與設定、LINE OA 事件追蹤整合、Meta CAPI 即時回傳、轉換數據儀表板，以及 ROI 分析報表。

### 2.4 模組四：競品監測與策略情報（Ad Hunter）

Ad Hunter 為客戶提供廣告策略與競品分析的數據支撐，使其投放決策從「憑感覺」轉向「數據驅動」。

系統能自動抓取指定競品或產業的廣告素材、文案、投放策略與受眾定位資訊，並透過 Telegram Bot 推送即時情報通知。分析結果整合至 Google Sheets 輸出視覺化報表，幫助客戶快速掌握市場趨勢、發現爆款素材靈感，並據此調整自身投放策略。

服務內容包含：競品廣告素材庫自動更新、投放趨勢分析報表、爆款素材即時推送、產業關鍵字熱度追蹤，以及自訂監測規則。

### 2.5 增值服務一：自控互動系統

對標 HDZ Bulk 的互動系統，提供客戶自行操控帳號群組的能力，適用於直播即時互動、貼文帶風向等場景。每組方案標配 30 組帳號，支援 Facebook 平台，未來逐步擴展至 Instagram 與 YouTube。

### 2.6 增值服務二：AI 行銷助手（規劃中）

結合大型語言模型（LLM）API，提供自動化廣告文案生成、社群貼文排程建議、受眾洞察分析等 AI 驅動的行銷輔助功能，作為第三階段的核心產品。

## 三、技術架構建議

基於現有技術能力，建議採用以 Cloudflare 生態系為核心的現代化 Serverless 與邊緣運算架構，確保系統具備極高彈性、低延遲與低維運成本。

### 3.1 整體架構概覽

全行銷的技術架構分為四個層次：**前端展示層**、**邊緣運算層**、**自動化整合層** 與 **基礎設施層**。

**前端展示層** 採用 React 19 搭配 TypeScript 與 Vite 構建極速單頁應用（SPA）。UI 層使用 Tailwind CSS v4 與 shadcn/ui 元件庫，打造現代化、高質感的會員管理面板與數據儀表板。相較於 HDZ Bulk 較為傳統的介面設計，全行銷的前端體驗將成為品牌差異化的重要一環。前端透過 Cloudflare Pages 部署，享受全球 CDN 加速。

**邊緣運算層** 全面擁抱 Cloudflare 生態系。核心 API 服務部署於 Cloudflare Workers，利用全球超過 300 個邊緣節點實現極低延遲的請求處理。Shadow Cloak 的流量過濾邏輯同樣運行於 Workers，確保在流量到達源站之前即完成毫秒級的訪客判斷與重定向。資料庫採用 Cloudflare D1（基於 SQLite）處理關聯性數據，如會員資料、訂單紀錄與歸因事件；搭配 Cloudflare KV 快取高頻讀取的設定檔、斗篷規則與即時狀態數據。

**自動化整合層** 於 Contabo VPS 自架 N8N 自動化工作流引擎，作為系統的「中央調度大腦」。N8N 負責以下關鍵任務：串接外部 SMM 供應商 API 進行訂單派發與狀態同步、處理 GodView 的 Meta CAPI 轉換回傳、管理 Telegram Bot 客服通知與 Ad Hunter 情報推送、與 Google Sheets 進行數據同步與報表生成，以及執行定時任務如訂單超時檢查與供應商健康監測。

**基礎設施層** 採用 GitHub 作為程式碼倉庫，搭配 GitHub Actions 實現 CI/CD 與 GitOps 流程。每次程式碼推送至主分支後，自動觸發測試、構建與部署流程，將前端部署至 Cloudflare Pages、Workers 程式碼部署至 Cloudflare Workers、後端服務部署至 Contabo VPS，確保開發迭代效率與系統穩定性。多個域名資源用於斗篷系統的域名輪替與品牌官網建設。

### 3.2 關鍵技術決策

| 技術選型 | 選擇方案 | 決策理由 |
| :--- | :--- | :--- |
| 運算平台 | Cloudflare Workers | 全球邊緣部署、冷啟動極快（V8 Isolates）、按請求計費成本可控 |
| 資料庫 | Cloudflare D1 + KV | D1 處理結構化查詢、KV 處理高頻快取，均與 Workers 深度整合 |
| 前端框架 | React 19 + Vite + Tailwind v4 | 團隊既有技術棧，開發效率最高 |
| 自動化引擎 | N8N（自架） | 開源免費、視覺化工作流、豐富的第三方整合節點 |
| CI/CD | GitHub Actions | 與 GitHub 深度整合、免費額度充足、社群生態成熟 |
| 伺服器 | Contabo VPS | 性價比極高，適合承載 N8N 與非邊緣運算任務 |

## 四、商業模式與定價策略建議

全行銷採用「基礎流量引流 + 高階技術服務變現」的分層商業模式，透過低門檻的基礎服務吸引大量用戶，再以獨家技術服務提升客單價與用戶黏性。

### 4.1 營收模式

| 方案類型 | 定價模式 | 建議價格區間 | 目標對象 | 服務內容 |
| :--- | :--- | :--- | :--- | :--- |
| **基礎流量服務** | 預先儲值、按件扣款 | 單次儲值 NT$500 起 | 微網紅、個人賣家、小型工作室 | 各平台按讚、追蹤、觀看等標準 SMM 服務。導入五級會員等級制（一般 → 銀 → 金 → 鑽石 → 尊皇），儲值累計越多、單價折扣越大。 |
| **進階互動訂閱** | 月費訂閱制 | NT$5,000 - $8,000/月 | 直播主、中型電商、公關公司 | 自控互動系統（30 組帳號），支援即時操控直播互動、貼文按讚與留言。年繳方案享額外折扣。 |
| **黑科技行銷套件** | 高階月費制 | NT$15,000 - $30,000/月 | 廣告投放團隊、灰產客戶、大型電商 | Shadow Cloak 斗篷系統（按流量級別計費）+ GodView 歸因系統（按綁定像素數量計費）。含專屬技術支援與優先客服。 |
| **企業客製化方案** | 專案報價 | NT$100,000 起 | 大型品牌、政治公關、跨國企業 | 整合 Ad Hunter 競品分析、全通路流量佈局、專屬自動化工作流建置與行銷顧問服務。 |
| **API 經銷商方案** | 批發價 + API 串接費 | 月費 NT$3,000 + 批發價 | 行銷代理商、其他 SMM 面板 | 開放 API 供經銷商串接，以批發價提供全行銷的服務，經銷商自行加價銷售。 |

### 4.2 定價策略與 HDZ Bulk 比較

全行銷的定價策略核心為：**基礎服務平價競爭，高階服務溢價變現**。

在基礎流量服務方面，定價略低於或持平 HDZ Bulk，以價格優勢吸引用戶遷移。在互動系統方面，HDZ Bulk 的 1 年方案為 NT$7,000/月（總計 $84,000），全行銷以 NT$5,000-$8,000/月的彈性區間提供更具競爭力的選擇 [5]。而黑科技行銷套件（Shadow Cloak + GodView）是 HDZ Bulk 與 iFans 完全不具備的服務，屬於藍海定價，具備高毛利空間。

### 4.3 金流方案

支援多元支付管道以降低儲值門檻：台灣本地支付（超商代碼、ATM 虛擬帳號、信用卡）透過藍新金流或綠界科技串接；國際支付透過 Stripe 支援 Apple Pay、Google Pay 與國際信用卡；加密貨幣支付（USDT/BTC）透過第三方支付閘道串接，滿足高隱私需求客戶。

## 五、目標客群分析

根據服務矩陣與市場調研，將目標客群分為四大類，並針對其核心痛點提供精準解決方案。

### 5.1 客群一：流量焦慮型（網紅、直播主、個人品牌）

此類客戶面臨社群平台自然觸及率持續下滑的困境——Facebook 的自然流量已幾乎無法發揮作用 [2]。他們需要快速、便宜且安全的基礎流量服務來建立社會認同（Social Proof），或在直播時需要即時互動來帶動買氣與氣氛。根據市場數據，台灣有超過 60% 的創作者內容集中於「娛樂」、「生活風格」與「時尚美妝」三大領域 [2]，這些創作者正是基礎流量服務的主力消費族群。

**對應方案**：基礎流量服務 + 進階互動訂閱。

### 5.2 客群二：轉換瓶頸型（電商賣家、廣告投放手）

面對廣告成本日益高漲與 iOS 隱私政策導致的追蹤失準，這類客戶急需精準的數據歸因與競品分析。台灣企業在社群媒體的平均行銷預算佔比已達 14.6% [1]，但許多投放者因無法準確衡量 ROI 而陷入「盲投」困境。GodView 歸因系統能幫助他們找回遺失的轉換數據，優化廣告模型；Ad Hunter 則能提供爆款素材靈感，突破轉換瓶頸。

**對應方案**：黑科技行銷套件（GodView + Ad Hunter）。

### 5.3 客群三：高風險投放型（特殊產業、灰產、跨境電商）

這類客戶的痛點在於廣告帳號極易被封禁，導致業務停擺與資金損失。保健食品、金融投資、減肥產品等產業的廣告投放者，長期面臨平台審核的高壓。Shadow Cloak 斗篷系統是他們的剛需，能有效規避平台審核機制，保護珍貴的廣告帳號資產與流量，確保業務連續性。

**對應方案**：黑科技行銷套件（Shadow Cloak 為核心）。

### 5.4 客群四：策略整合型（品牌方、行銷代理商、政治公關）

大型品牌與代理商需要的不僅是單點服務，而是從口碑佈局、輿論操作到數據追蹤的全方位整合方案。政治公關在選舉期間對論壇口碑操作（PTT、Dcard）與新聞發布有大量且集中的需求。

**對應方案**：企業客製化方案 + API 經銷商方案。

| 廣告歸因系統 | 無 | 無 | 有（GodView） |
| 競品分析工具 | 無 | 無 | 有（Ad Hunter） |
| 自控互動系統 | 有（僅 FB） | 無 | 有（FB，逐步擴展） |
| API 經銷商方案 | 未公開 | 有 | 有 |
| 技術架構 | 傳統伺服器 | 自主開發 | Cloudflare 邊緣運算 |
| 支付方式 | 銀行轉帳為主 | 多元（含加密貨幣） | 多元（含加密貨幣） |

### 6.2 核心競爭優勢

**技術降維打擊**：傳統平台多依賴開源或購買的 SMM 面板程式（如 Perfect Panel、JETKINGS 等），功能同質化嚴重。全行銷擁有自主開發的 Cloudflare 邊緣運算架構與 N8N 自動化能力，系統反應速度更快、擴展性更強，且具備獨家的斗篷與歸因技術，形成難以複製的技術壁壘。

**從「虛榮指標」到「真實轉換」的閉環**：競品僅能提供按讚、追蹤等表面數據（Vanity Metrics），而全行銷透過 GodView 系統，能將社群流量與實際商業轉換（如 LINE 加好友、購買行為）串聯起來，為客戶提供具備實質商業價值的解決方案。這不僅大幅提升服務的不可替代性，更將客戶關係從「一次性交易」升級為「長期依賴」。

**自動化營運與低邊際成本**：藉由 N8N 與 GitHub Actions，實現從接單、派單、供應商切換、客服通知到報表生成的全自動化。在相同營收規模下，所需的人力維運成本遠低於競品，具備更高的利潤空間與價格競爭力。HDZ Bulk 在 2025-2026 年間曾經歷團隊交接問題 [5]，凸顯了過度依賴人力的風險，而全行銷的自動化架構能有效規避此類問題。

**現有資源的槓桿效應**：24 個 LINE OA、10 個 ADS 像素、Facebook BM、多個域名資源與 Contabo VPS 等既有資產，使全行銷在啟動階段即具備相當的基礎設施，無需從零建設，大幅縮短上線時程並降低初始投資。

## 七、發展路線圖

為確保資源有效配置與風險可控，建議分三階段推進全行銷的發展，每階段設定明確的里程碑與關鍵績效指標（KPI）。

### 第一階段：基礎建設與冷啟動（第 1-3 個月）

此階段的核心目標是完成最小可行產品（MVP）並獲取首批付費用戶。

主要任務包含：完成會員管理面板與儲值/下單系統的前端開發（React 19 + shadcn/ui）；部署核心 API 至 Cloudflare Workers 並建立 D1 資料庫架構；透過 N8N 串接 3-5 家上游 SMM 供應商 API，上線基礎流量服務（優先支援 FB、IG、YT、TikTok）；整合藍新金流或綠界科技，開通超商繳費與 ATM 轉帳；利用現有 LINE OA 與 Telegram 社群進行種子用戶邀請與封閉測試。

**里程碑**：平台正式上線、累計 500 名註冊會員、月營收突破 NT$50,000。

### 第二階段：技術變現與差異化（第 4-6 個月）

此階段的核心目標是推出獨家技術服務，建立市場差異化定位。

主要任務包含：正式推出 Shadow Cloak 斗篷系統，針對廣告投放社群進行精準推廣；正式推出 GodView 歸因系統，與現有 LINE OA 與 FB BM 深度整合；啟動 Ad Hunter 競品分析的 Beta 版本；擴展基礎流量服務至 PTT、Dcard、Google Map 評價等台灣本土化服務；透過技術部落格、案例分享與社群口碑進行內容行銷，建立專業品牌形象。

**里程碑**：黑科技套件付費用戶達 50 家、累計會員突破 3,000 名、月營收突破 NT$300,000。

### 第三階段：生態擴張與規模化（第 7-12 個月）

此階段的核心目標是建立經銷商生態系並探索海外市場。

主要任務包含：開放 API 供經銷商串接，建立代理分銷體系；擴展海外市場，優先瞄準香港、馬來西亞、新加坡等華語市場；研發 AI 行銷助手（文案生成、素材建議），作為新的營收增長引擎；建立自控互動系統並逐步擴展至 Instagram 平台；評估公司登記與正式法人化。

**里程碑**：經銷商合作夥伴達 20 家、累計會員突破 10,000 名、月營收突破 NT$1,000,000。

## 八、風險評估與應對策略

在營運過程中，需密切關注並防範以下五大潛在風險。

### 8.1 平台政策與演算法變更風險

**風險描述**：社群平台（如 Meta、Google）頻繁更新防作弊機制與隱私政策，可能導致基礎流量服務的帳號被大量封禁，或斗篷系統的偽裝邏輯被識破。

**應對策略**：持續監測平台動態，利用 Ad Hunter 系統收集政策變更情報，並保持 Shadow Cloak 演算法的敏捷迭代。建立多供應商、多技術路線的冗餘機制，避免單點故障。同時逐步提高高階技術服務的營收佔比，降低對基礎流量服務的依賴。

### 8.2 上游供應商穩定性風險

**風險描述**：基礎流量服務高度依賴海外 SMM API 供應商，若供應商倒閉、服務品質下降或價格大幅上漲，將直接影響客戶體驗與利潤率。

**應對策略**：透過 N8N 建立多供應商自動備援機制（Failover），當主供應商的 API 回應異常或交付延遲時，系統自動將訂單切換至備用供應商。同時建立供應商評分系統，定期評估各供應商的交付品質、速度與穩定性，動態調整訂單分配比例。

### 8.3 法律與合規風險

**風險描述**：提供流量操作與斗篷服務可能違反社群平台的服務條款，在極端情況下可能面臨法律訴訟。論壇口碑操作若涉及不實言論，亦可能觸犯相關法規。

**應對策略**：在平台服務條款中明確免責聲明，告知用戶服務性質與潛在風險。建立客戶產業篩選機制，嚴格拒絕涉及詐騙、非法博弈、毒品等嚴重違法業務的客戶。確保金流管道的合規性，優先使用正規第三方支付。在公司法人化階段，諮詢專業律師完善法律架構。

### 8.4 市場競爭與價格戰風險

**風險描述**：台灣 SMM 市場已有 HDZ Bulk、iFans、KsD Shop、MyFan 等多家競品，新進者可能面臨激烈的價格競爭，壓縮利潤空間。

**應對策略**：避免在基礎流量服務上與競品進行純粹的價格戰。全行銷的核心策略是透過 Shadow Cloak、GodView 與 Ad Hunter 等獨家技術服務建立差異化定位，將競爭維度從「價格」提升至「價值」。基礎流量服務作為獲客工具，高階技術服務作為利潤引擎。

### 8.5 技術人才與團隊擴張風險

**風險描述**：初期以創辦人為核心的技術團隊，在業務快速成長後可能面臨人力瓶頸，影響產品迭代速度與客服品質。

**應對策略**：在第一階段即建立完善的技術文件與自動化流程，降低對個人能力的依賴。優先招募兼職或遠端的前端開發者與客服人員。利用 N8N 自動化盡可能減少人工介入的環節，確保在團隊規模有限的情況下仍能維持高效營運。
