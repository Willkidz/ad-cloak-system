> **TL;DR**: 本文件定義了斗篷管理後台對齊「火鳥」系統的前端 UI/UX 規範（v1.8 完成）。「添加廣告」頁面採用左右分欄佈局，左欄包含五步驟漸層導航（選擇模版→添加分流→創建斗篷→廣告投放→提交信息）、域名下拉、LINE 鏈接批量添加、多鏈接分配策略（隨機/輪詢/同 IP 固定）、像素設置（TK/FB/GA/Google Ads）與黑名單；右欄包含瀏覽器語言、操作系統、國家等多選過濾條件及安全頁配置（模板或鏈接，支援 react-quill-new 富文本編輯器）。「廣告日誌」頁面有 5 個 Tab（全部/訪問/按鈕點擊/安全內頁/斗篷攔截），攔截原因自動中文轉換（如 `geo_filter_US` → `國家過濾::US`）。UI 主色調為紫色 `#7c3aed`，使用 shadcn/ui + react-select。

# 斗篷管理後台前端 UI 設計：火鳥對齊與表單

本文檔詳細說明了「斗篷管理後台」中，為對齊「火鳥」系統所進行的前端 UI/UX 設計，主要涵蓋「添加廣告」頁面的表單結構、各類下拉選單的具體選項，以及「廣告日誌」頁面的顯示邏輯與規範。

---

## 一、添加廣告頁面

此頁面為系統核心功能，採用左右分欄佈局，引導用戶通過五個步驟完成廣告的創建與配置。設計已於 v1.8 完成。

### 左欄結構

<step id="left-column-nav">

**1. 漸層圓形導航**
- 選擇模版
- 添加分流
- 創建斗篷
- 廣告投放
- 提交信息

</step>

<step id="left-column-form">

**2. 鏈接**：下拉選擇域名。
**3. 標題**：廣告活動的標題。
**4. 廣告落地頁**：由「國家/分類」和「模板名稱」兩個下拉選單並排組成。
**5. Line 鏈接**：支持動態新增多行，並提供批量添加彈窗。
**6. 多鏈接設置**：提供「隨機打開」、「輪詢打開」、「同 IP 固定」三個選項。
**7. 允許客戶群**：可選擇「電腦端」或「移動端」。
**8. 僅允許住宅 IP**：開關選項。
**9. 像素設置**：包含 TK、FB、GA、Google Ads 的像素 ID 輸入框，並附有 tooltip 說明。
**10. 狀態**：提供「上架」和「下架」的單選按鈕。
**11. 黑名單**：可動態新增過濾條件，每行包含「條件下拉選單」、「輸入值」和「刪除按鈕」。

</step>

### 右欄結構

<step id="right-column-form">

**1. 允許瀏覽器語言**：多選下拉菜單。
**2. 允許訪客操作系統**：多選下拉菜單。
**3. 允許操作系統版本**：文本輸入框。
**4. 允許國家**：多選下拉菜單。
**5. 允許省州**：文本輸入框。
**6. 允許流量來源**：多選下拉菜單。
**7. 安全頁類型**：可選「安全落地頁模板」或「安全頁鏈接」。
**8. 安全落地頁模板**：由兩個下拉選單並排組成。
**9. 安全頁面點擊**：可選「顯示內容」或跳轉至「安全鏈接」。
**10. 內容編輯器**：若選擇「顯示內容」，則提供 `react-quill-new` 富文本編輯器；否則為跳轉鏈接輸入框。

</step>

### 底部設計

- **提示文字**：橘色字體，用於建議落地頁和建議安全頁。
- **提交按鈕**：紫色（`#7c3aed`）按鈕，用於提交整個表單。

## 三、廣告日誌頁面

此頁面用於展示廣告的詳細日誌，設計已於 v1.8 完成。

### 頁面佈局

<rule id="log-tabs">

包含 5 個 Tab 頁籤，用於分類篩選日誌：
- 全部日誌
- 訪問日誌
- 按鈕點擊
- 安全內頁點擊
- 斗篷攔截

</rule>

### 列表欄位

| 欄位 | 說明 |
| :--- | :--- |
| 序號 | # |
| 訪問時間 | 記錄訪問的日期與時間 |
| 訪問域名/來源 | 顯示訪問的域名或流量來源 |
| 國家/訪問IP | 訪客的地理位置與 IP 地址 |
| 訪客ID | 系統分配的唯一訪客標識 |
| 語言 | 訪客瀏覽器語言 |
| 設備(UA) | 訪客的 User Agent 字串 |
| 狀態 | 標記為「訪問日誌」或「斗篷攔截」 |
| 日誌(攔截原因) | 如果被攔截，顯示具體原因 |

### 顯示邏輯

<rule id="log-display-logic">

- **訪問域名**：若 `domain` 字段有值，則顯示該域名；若為 `null` 或空，則顯示「火鳥」。
- **攔截原因中文轉換**：
  - `geo_filter_US` → `國家過濾::US`
  - `blocked_asn_XXXX` → `ASN黑名單::XXXX`
  - `valid_traffic` → `有效流量`
- **狀態標籤**：
  - `safe` → 紅色標籤「斗篷攔截」
  - `money` → 綠色標籤「訪問日誌」
- **分頁**：每頁顯示 20 筆記錄，並提供搜索和刷新功能。

</rule>
