# 斗篷過濾功能測試指南

為了確保 shadow-cloak 的各項過濾機制能夠準確攔截不符合條件的流量，我們在系統中建立了 5 個專用的測試廣告。每個測試廣告都對應一個獨立的網域，並且僅啟用單一過濾條件。這樣的設計能夠排除其他過濾規則的干擾，讓我們可以針對單一變數進行精確的測試與驗證。

在開始測試之前，請確保您準備好適當的測試環境。您將需要穩定的台灣住宅網路（例如家用 Wi-Fi 或手機 4G/5G 網路），以及可用的電腦與手機裝置。此外，為了模擬跨國或非住宅網路的訪問，請準備一套能夠切換不同國家節點或機房 IP 的 VPN 工具。

以下是每個測試廣告的詳細設定與測試步驟總覽表：

| 測試項目 | 測試域名 | 設定條件 | 預期通過情況（顯示落地頁） | 預期被擋情況（顯示安全頁） |
|---------|---------|---------|------------------------|------------------------|
| **國家過濾** | `mopliv.site` (T-01) | 只允許 `TW` (台灣) | 關閉 VPN，使用台灣本地網路直接訪問網域。 | 開啟 VPN 連線至日本或美國等非台灣節點後訪問。 |
| **語言過濾** | `raxnto.shop` (T-02) | 只允許 `zh-TW` (繁中) | 使用系統與瀏覽器預設為繁體中文的環境訪問。 | 將瀏覽器主要語言設定更改為英文 (English) 並重啟後訪問。 |
| **設備過濾** | `zuntek.site` (T-03) | 只允許手機端訪問 | 使用智慧型手機（iPhone 或 Android）的內建瀏覽器訪問。 | 使用桌上型電腦或筆記型電腦（Windows 或 Mac）訪問。 |
| **強制 fbclid** | `velphi.shop` (T-04) | 強制要求 `fbclid` 參數 | 在網址後方手動加上參數訪問，例如 `/?fbclid=test123456`。 | 直接訪問主網域，網址不帶有任何查詢參數。 |
| **住宅 IP 過濾** | `fyntro.lol` (T-05) | 僅允許住宅 IP 訪問 | 使用一般電信商的手機 4G/5G 網路或家用寬頻訪問。 | 開啟 VPN，特別是連接至 AWS、GCP 等知名資料中心的機房 IP 後訪問。 |

請依照上述表格的指示，逐一在您的設備上進行操作。如果任何一項測試的實際結果與預期不符，請立即記錄該次訪問的時間、IP 位址以及使用的設備資訊，以便我們進一步排查系統日誌。
