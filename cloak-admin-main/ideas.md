# 斗篷管理後台 - 設計方案

這是一個管理後台系統，需要高效、專業、易用的介面設計。

## 方案一：暗色科技風（Dark Tech Command Center）

**設計運動**：Cyberpunk-inspired Dashboard UI，融合軍事指揮中心的沉穩與科技感。

**核心原則**：
1. 暗色主調搭配紫色（#7c3aed）作為品牌色，營造專業且神秘的氛圍
2. 資訊密度優先，一屏展示最多有效資訊
3. 清晰的視覺層級，通過顏色和陰影區分區塊

**色彩哲學**：深色背景（#0f172a / #1e293b）搭配紫色主色調（#7c3aed），白色文字，綠色/紅色用於狀態指示。暗色減少視覺疲勞，適合長時間使用的管理後台。

**佈局範式**：固定左側導航欄（深色），右側為主內容區域。導航欄寬度適中，圖標+文字組合。

**標誌元素**：
- 微妙的漸變邊框和卡片陰影
- 數據卡片帶有圖標和微動畫

**交互哲學**：快速響應，操作後立即反饋。表格操作使用行內按鈕，彈窗用於確認和表單。

**動畫**：頁面切換淡入，卡片懸停微浮起，按鈕點擊微縮放。

**字體系統**：系統字體堆疊，數字使用等寬字體。

## 方案二：極簡白色管理面板（Minimal White Admin）

**設計運動**：Swiss Design / International Style，強調功能性和清晰度。

**核心原則**：
1. 白色為主的清爽介面，紫色作為強調色
2. 大量留白，降低認知負擔
3. 嚴格的網格系統和對齊

**色彩哲學**：純白背景，灰色層級區分，紫色（#7c3aed）僅用於主要操作按鈕和選中狀態。

**佈局範式**：頂部導航 + 側邊欄混合，內容區域寬敞。

**標誌元素**：
- 細線邊框和微妙陰影
- 大面積留白

**交互哲學**：簡潔直觀，減少視覺噪音。

**動畫**：極簡過渡，幾乎無裝飾性動畫。

**字體系統**：Inter 字體家族。

## 方案三：深色側邊欄 + 淺色內容區（Hybrid Professional）

**設計運動**：Material Design 3 風格的企業級管理面板，結合深色導航與淺色工作區。

**核心原則**：
1. 深色側邊欄（#1e1b4b → #312e81 漸變）提供穩定的導航錨點
2. 淺色主內容區確保數據可讀性
3. 紫色（#7c3aed）貫穿品牌識別

**色彩哲學**：側邊欄使用深紫/靛色漸變，主內容區使用淺灰白色（#f8fafc），卡片為純白。紫色用於活動狀態、按鈕和重要指標。橙色/紅色/綠色用於警告/錯誤/成功狀態。

**佈局範式**：固定寬度深色側邊欄（220px），右側為可滾動的淺色內容區。頂部有麵包屑和用戶頭像。

**標誌元素**：
- 側邊欄活動項目帶有紫色左邊框指示器
- 數據卡片帶有彩色圖標背景圓圈
- 表格行懸停時微妙的背景色變化

**交互哲學**：操作按鈕分組在表格行右側，主要操作使用紫色填充按鈕，次要操作使用幽靈按鈕。刪除操作必須二次確認。所有操作後有 Toast 通知。

**動畫**：側邊欄項目切換時內容區淡入（150ms），表格行懸停背景過渡（200ms），彈窗使用 scale + fade 組合進入。

**字體系統**：Noto Sans TC 作為主字體（繁體中文優化），JetBrains Mono 用於代碼和 ID 顯示。標題 600 weight，正文 400 weight。

## 選定方案

選擇**方案三：深色側邊欄 + 淺色內容區（Hybrid Professional）**。

理由：這是管理後台最經典且實用的佈局模式，深色側邊欄提供穩定的導航體驗，淺色內容區確保數據表格和表單的可讀性。紫色品牌色（#7c3aed）與深色側邊欄搭配效果最佳，同時符合用戶指定的主色要求。
